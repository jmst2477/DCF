# DCF 계산기

종목(티커)을 넣으면 DCF로 **지금·내년·내후년 적정가**를 계산하는 페이지입니다. 시킹알파 추정치(자동 가져오기, 캡처, 재무제표 PDF)를 넣으면 더 정확해집니다.
바로가기: `https://<배포주소>/?t=AVGO`

## 계산 방식 (하나, 강의 방식)
DCF 원작자 강의와 같은 계산입니다. 최근 매출에서 시작해 **3년** 동안 고정 가정(매출 성장률, 영업이익률, 법인세율 21%, 감가상각비·캐펙스·운전자본 = 매출의 %)으로 FCFF를 만들고, 할인율로 현재가치를 구한 뒤 3년차 FCFF × (1+g)/(할인율−g)를 영구가치로 더합니다. 자기자본 = 기업가치 − 차입금 + 현금. 예측 연수 칸을 5로 바꾸면 강의 마이크론 예시($1,246.83)와 똑같이 계산됩니다. "엑셀 다운로드"는 강의 시트와 같은 배치·수식입니다.
- 추정치를 5년치 넣어도 계산은 3년까지만 합니다. 4~5년차 추정치는 내년·내후년 적정가에 씁니다.
- 내년 적정가 = 1년차 매출에서 출발해 2~4년차를 같은 방식으로 예측한 값, 내후년 = 2년차에서 출발해 3~5년차. 성장률은 그 창의 매출 추정치 연평균이고, 추정치가 모자라면 마지막 성장률을 이어 쓰고 * 표시를 합니다. 현금·차입금·주식수는 지금과 같다고 봅니다.
- P/E 방식 적정가도 함께 보여 줍니다: 적정가 = 예상 EPS × 적정 P/E. 지금 = 1년차 EPS, 내년 = 2년차, 내후년 = 3년차 (시킹알파 EPS 추정치, 없으면 매출 × 이익률 × (1 − 세율) ÷ 주식수로 계산하고 † 표시). 적정 P/E 기본값은 PEG 1.5 × EPS 연평균 성장률(%) (10~40배), EPS 추정치가 없으면 20배. 칸에서 직접 바꿀 수 있습니다.
- 시킹알파 캡처 2장: Earnings → Estimates → Annual에서 ① CONSENSUS EPS ESTIMATES 표, ② CONSENSUS REVENUE(매출) ESTIMATES 표를 각각 캡처해 칸에 하나씩 넣습니다. 매출 표 → 성장률(추정치 연평균), EPS 표 → 영업이익률(평균). 나머지는 티커 조회로 채웁니다.
- 자동 가져오기(북마클릿): 1번 칸의 "DCF로 보내기" 버튼을 북마크바로 끌어다 놓고, 시킹알파에 로그인한 브라우저에서 종목 페이지를 연 채 누르면 그 브라우저 안에서 시킹알파 추정치(매출·EPS 컨센서스)를 읽어 DCF 창으로 보냅니다(postMessage, 안 되면 복사 → Ctrl+V). 로그인 정보는 사이트로 오지 않습니다.
- 영업이익률을 EPS로 추정할 때: 시킹알파 EPS는 조정 EPS라 주식보상비용(SBC)과 인수 무형자산 상각비가 빠져 있습니다. 그래서 이익률에서 SBC/매출(최근 실적)을 빼고, 감가상각비는 캐펙스와 같게 둡니다.
- (선택) 시킹알파 Financials → Annual의 Income Statement / Balance Sheet / Cash Flow PDF 3개를 올리면 실적·현금·차입금·주식수를 PDF 값으로 바꿉니다. "Finance Div." 항목(금융 자회사 차입금·대출채권)은 뺍니다.
- 티커 조회: `/api/dcf-inputs` (Vercel 함수, 야후 파이낸스)가 최근 4년 실적, 주가, 주식수, 현금, 차입금(리스 제외), 매출 컨센서스(보통 2개 연도)를 가져옵니다.
- 직접 고친 칸은 다시 조회해도 바뀌지 않습니다. 같은 종목에서 **계산**을 다시 누르면 주가만 새로 받습니다. 처음부터 다시 불러오려면 초기화 후 계산을 누릅니다.

화면은 토스증권처럼 회색 바탕에 흰 카드, 오르면 빨강·내리면 파랑입니다.

## 파일
- `api/dcf-inputs.js` 티커 → DCF 입력값 (서버, Vercel)
- `index.html`, `css/style.css` 화면
- `js/dcf.js` DCF 계산 (엑셀 수식과 1:1)
- `js/parser.js` OCR 글자 → 연도별 매출 추정치
- `js/sapdf.js` 시킹알파 재무제표 PDF → 실적·대차대조표 값
- `js/app.js` 화면 동작, 자동 가정, OCR, Claude API, 엑셀 내보내기

입력값은 브라우저(localStorage)에만 저장됩니다. 자동 조회는 Vercel 배포에서만 동작하고, GitHub Pages 같은 정적 호스팅에서는 직접 입력하면 됩니다.
