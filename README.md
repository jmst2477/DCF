# DCF 계산기

종목(티커)을 넣으면 매출 추정치가 있는 해까지 DCF를 바로 계산하고, 시킹알파 **Earnings → Estimates** 캡처로 3~5년차 매출을 바꿀 수 있는 페이지입니다.
바로가기: `https://<배포주소>/?t=GOOGL`

## 기본 방식 (강의 방식)
처음 화면은 DCF 원작자 강의(마이크론 예시)와 같은 계산입니다. 최근 매출에서 시작해 5년 동안 **고정 가정**(매출 성장률, 영업이익률, 법인세율 21%, 감가상각비·캐펙스·운전자본 = 매출의 %)으로 FCFF를 만들고, 할인율로 현재가치를 구한 뒤 5년차 FCFF × (1+g)/(할인율−g)를 영구가치로 더합니다. 자기자본 = 기업가치 − 차입금 + 현금. 마이크론 예시 입력이면 1주당 $1,246.83이 나옵니다. "엑셀 다운로드"는 강의 시트와 같은 배치·수식입니다.
- 시킹알파 캡처 2장: Earnings → Estimates → Annual에서 ① CONSENSUS EPS ESTIMATES 표, ② CONSENSUS REVENUE(매출) ESTIMATES 표를 각각 캡처해 칸에 하나씩 넣습니다 (Ctrl+V는 마지막으로 누르거나 가리킨 칸, 없으면 빈 칸에 들어감). 두 표를 한 장에 찍어 아무 칸에 넣어도 됩니다. 매출 표 → 성장률(추정치 연평균), EPS 표 → 영업이익률(평균). 나머지는 티커 조회로 채웁니다.
- 직접 고친 칸은 노란색으로 남고 다시 조회해도 바뀌지 않습니다.
- 위의 "연도별 (고급)"을 고르면 아래의 연도별 방식으로 계산합니다.

## 흐름 (연도별, 고급)
1. 티커 입력 → `/api/dcf-inputs` (Vercel 함수, 야후 파이낸스, 키 불필요)가 최근 4년 실적, 주가, 주식수, 현금, 차입금(리스 제외), 매출 컨센서스(보통 2개 연도)를 가져옵니다.
2. 나머지 가정은 자동으로 채웁니다 (모두 화면에서 수정 가능)
   - 예측 기간: 매출 추정치가 있는 마지막 해까지만 (예: 추정치가 FY2029까지면 FY2029까지 계산하고 그다음 해부터 영구가치)
   - 운전자본/매출: 최근 재무제표 (매출채권+재고−매입채무−미지급비용)÷매출, 20% 넘으면 20%로 제한(금융 자회사 채권 혼입 의심)
   - 베타 → CAPM 자기자본비용 참고값 (무위험이자율 4.2% + 베타 × 5%), SBC/매출은 체크 시 FCFF에서 차감
   - 영업이익률·감가상각비·캐펙스 비율: 최근 회계연도 값
   - 정상화 캐펙스 = 최근 4년 평균 캐펙스%, 정상화 감가상각비 = max(평균 D&A%, 캐펙스×0.8)
   - 할인율 8%, 영구성장률 2%, 운전자본 0 (강의 기본값)
3. 시킹알파 Estimates 캡처를 올리면 OCR(Tesseract.js, 브라우저 안)이나 Claude API(선택)로 읽습니다. Revenue(매출) 표 → 연도별 매출, EPS 표 → 영업이익률 추정(EPS × 주식수 ÷ (1 − 세율) ÷ 매출, 조정 EPS라 SBC 차감 켬), EBIT 표가 있으면 EBIT 우선, EBITDA 표 → 감가상각비/매출(EBITDA−EBIT), Capital Expenditure 표 → 캐펙스/매출. 추정치가 없는 칸(운전자본 등)은 최근 실적을 그대로 쓰고 점선으로 표시합니다.
4. (선택) 시킹알파 Financials → Annual의 Income Statement / Balance Sheet / Cash Flow PDF 3개를 올리면 실적·현금·차입금·주식수를 PDF 값으로 바꿉니다 (pdf.js, 브라우저 안). "Finance Div." 항목(금융 자회사 차입금·대출채권)은 차입금과 운전자본에서 뺍니다. 이전 값과 PDF 값을 표로 보여 줍니다.
5. 결과에 현재가가 가정하는 영구성장률·영업이익률(역DCF)이 함께 나옵니다.
6. "엑셀 다운로드"는 「DCF 개선판 v2」와 같은 셀 배치·수식의 .xlsx를 만듭니다.

같은 종목에서 **계산**을 다시 누르면 주가만 새로 받고, 올린 캡처·PDF와 직접 고친 값은 그대로 둡니다. 처음부터 다시 불러오려면 초기화 후 계산을 누릅니다.

화면: 맨 위에 1주당 적정가치·현재 주가·상승 여력, 그 아래 1) 매출 추정치 캡처 2) 재무제표 PDF, 세부 가정·현금흐름·민감도·엑셀은 "자세히 보기" 안에 있습니다.

## 파일
- `api/dcf-inputs.js` 티커 → DCF 입력값 (서버, Vercel)
- `index.html`, `css/style.css` 화면
- `js/dcf.js` DCF 계산 (엑셀 수식과 1:1)
- `js/parser.js` OCR 글자 → 연도별 매출 추정치
- `js/sapdf.js` 시킹알파 재무제표 PDF → 실적·대차대조표 값
- `js/app.js` 화면 동작, 자동 가정, OCR, Claude API, 엑셀 내보내기

입력값은 브라우저(localStorage)에만 저장됩니다. 자동 조회는 Vercel 배포에서만 동작하고, GitHub Pages 같은 정적 호스팅에서는 직접 입력하면 됩니다.
